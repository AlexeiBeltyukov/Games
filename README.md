
# Games

Учебные игры на C++. Каждая — в своей папке.

## Игры

- **GuessGame** — «Угадай число». Компьютер загадывает число от 1 до 100, у игрока 7 попыток.
- **Viselitsa** — «Виселица». Компьютер загадывает слово, игрок угадывает буквы. 6 жизней.

## Как собрать

1. Открой Code::Blocks.
2. File - Open - выбери .cbp файл нужной игры.
3. F9 — собрать и запустить.
