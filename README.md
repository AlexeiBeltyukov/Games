# Games

Учебные игры и программы на C++. Каждая — в своей папке.

## Проекты

- **GuessGame** — «Угадай число». Компьютер загадывает число от 1 до 100, у игрока 7 попыток.
- **Viselitsa** — «Виселица». Компьютер загадывает слово, игрок угадывает буквы. 6 жизней.
- **Temperatura** — Конвертер температур (C / F / K).
- **Medicina** — Анализатор здоровья: расчёт ИМТ, категория, рекомендация.

## Как собрать

1. Открой Code::Blocks.
2. File -> Open -> выбери .cbp файл нужного проекта.
3. F9 — собрать и запустить.
